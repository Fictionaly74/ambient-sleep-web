# Ambient audio sources

All audio assets are stored locally with the site. Source/license notes are kept here so the app remains auditable even if conversational context is forgotten.

| Local file | Source title | Author | Source page | License | Notes |
| --- | --- | --- | --- | --- | --- |
| `rain.mp3` | Wind in a cornfield | Joseph SARDIN | https://bigsoundbank.com/wind-in-a-cornfield-s1097.html | CC0 / public-domain equivalent | Exact former `breeze.mp3` asset. The user preferred its rain-like texture, so it is now used for Rain. |
| `wave.mp3` | Sea Waves | Joseph SARDIN | https://bigsoundbank.com/sea-waves-s0698.html | CC0 / public-domain equivalent | Stereo Atlantic-ocean wave soundscape. |
| `breeze.mp3` | Wind in the Trees | Joseph SARDIN | https://bigsoundbank.com/forest-wind-in-the-trees-s0904.html | CC0 / public-domain equivalent | Realistic stereo wind / vegetation soundscape, 03:38, microphones aimed into forest trees. |
| `forest.mp3` | Forest | Joseph SARDIN | https://bigsoundbank.com/forest-s0100.html | CC0 / public-domain equivalent | Stereo forest ambience. |

The `none` / 無音 option has no audio asset.
